## Google Search Console setup

These steps require the owner's Google and DNS accounts; no verification token has been invented or installed.

1. Open [Google Search Console](https://search.google.com/search-console/).
2. Add a **Domain** property named `nooralizahar.web.id`.
3. Copy the TXT verification value Google supplies.
4. In MyDomaiNesia, open the domain's DNS Management and add a **TXT** record at `@` using that exact value. Keep the existing website records.
5. Return to Search Console and verify ownership. Keep the TXT record after verification.
6. Under **Sitemaps**, submit `https://nooralizahar.web.id/sitemap.xml`.
7. Use **URL Inspection** for `https://nooralizahar.web.id/`, test the live URL, then request indexing.

The preferred canonical hostname is the root domain. If adding `www` in Vercel, redirect it to `https://nooralizahar.web.id/`.
